# Contexto del proyecto

## Objetivo

Wanderlust Explorer es una aplicación web orientada a descubrir experiencias de viaje. Los requisitos funcionales oficiales de 4Geeks Academy están recogidos en `specs/requirements.md`.

Las páginas y rutas previstas se definen en `specs/requirements.md`; este documento mantiene el contexto general sin duplicar sus requisitos.

## Alcance

Este documento registra el contexto general y no sustituye los requisitos funcionales. Los requisitos y sus criterios de aceptación deben proceder del enunciado oficial y mantenerse en `specs/requirements.md`.

## Tecnologías verificadas

- Next.js 16 con App Router.
- React 19.
- TypeScript.
- Tailwind CSS 4.
- npm como gestor reflejado por `package-lock.json`; los scripts disponibles están definidos en `package.json`.

## Restricciones

- El enunciado oficial de 4Geeks Academy es la fuente de verdad para el alcance funcional.
- No inventar requisitos cuando falte información.
- Conservar la estructura existente de Next.js.
- Las decisiones técnicas pendientes deben aprobarse antes de tratarse como decisiones del proyecto.
